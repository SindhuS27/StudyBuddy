# 🎓 StudyBuddy – Your Academic BFF

StudyBuddy is a smart academic assistant built with Python, helping you:
- Track subjects and topics
- Record marks & view performance charts
- Set study reminders
- Get cute motivational quotes 💖

> Made with 💕 by Sindhu

## 💻 Built With
- Python `tkinter`
- SQLite
- Matplotlib
